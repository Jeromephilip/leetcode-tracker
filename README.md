# 🧠 LeetCode Progress Tracker

This project is a **LeetCode Progress Tracker** designed to help users monitor their problem-solving journey and optimize their study schedule using smart algorithms and intuitive UI features. Built as a **Chrome Extension + Web Dashboard**, it integrates seamlessly with the LeetCode platform to provide personalized insights and daily problem recommendations.

---

## 🚀 What It Does

- **Automated Progress Tracking**: Syncs your LeetCode profile to fetch solved problems, difficulty distribution, and recent submissions.
- **Ebbenhaus Forgetting Curve Reminders**: Recommends problems to revisit based on spaced repetition to strengthen long-term memory retention.
- **Personalized Study Planner**: Prioritizes topics you're weak at, ensuring focused improvement over time.
- **Clean Dashboard UI**: A modern interface that displays your current stats, trends, and upcoming practice tasks.
- **Chrome Extension Popup**: Instantly view your daily recommended problems and quick stats directly from your browser.
- **Detailed Problem Insights**: See metadata for each question (e.g., tags, difficulty, last solved date) and track performance over time.

---

## 🧩 Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS  
- **Chrome Extension**: Manifest V3 with React UI  
- **Data Fetching**: React Query  
- **LeetCode Integration**: [`leetcode-query`](https://www.npmjs.com/package/leetcode-query)

---

## 💡 Why It Exists

While LeetCode provides a powerful platform for practice, it lacks personalized study insights. This project fills that gap by automating review schedules and helping users retain knowledge—not just solve problems once. Inspired by effective learning methodologies, this tracker aims to be your companion in becoming a stronger problem solver over time.
